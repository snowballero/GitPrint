<h1 id="Install">Installation</h1>
<h3>Windows</h3>

1. Clone the repo
```bash
git clone https://github.com/snowballero/gitprint
```
1.1 Change directory to it
```bash
cd gitprint
```
1.2 Execute the file
```bash
python gitprint.py
```

<h3>Linux / MacOS</h3>

1. Clone the repo
```bash
git clone https://github.com/snowballero/gitprint
```
1.1 Change directory to it
```bash
cd gitprint
```
1.2 Execute the file
```bash
python3 gitprint.py
```
<br>
<h3>Or use an all in one command</h3>
<h2>Windows</h2>

```bash
git clone https://github.com/snowballero/gitprint; cd gitprint; python gitprint.py
```

<h2>Linux / MacOS</h2>

```bash
git clone https://github.com/snowballero/gitprint && cd gitprint && python3 gitprint.py
```
